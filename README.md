**KUNI STAT** — An original, zero-dependency, offline-first national statistics portal for Japan with real official figures (1995–2025), interactive multi-series SVG charts, a 47-prefecture regional cartogram, citizen purchasing-power & wage calculators, release calendar, and CSV/JSON open data exports.

## Run it

```sh
node serve.ts
# or build the submission dossier:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
